Privacy Policy

Last updated: 5 October 2026

This policy covers the Zuppi YouTube channel (@Zuppi.worldwide) and Kuki, a private assistant application that the channel owner uses to manage the channel through the YouTube API Services.

1. Who uses Kuki

Kuki is not a public product. Only the Zuppi channel owner signs in to it, with their own Google account. Viewers of the channel never sign in to Kuki and Kuki collects no information from viewers.

2. Data Kuki accesses

With the owner's permission (Google OAuth), Kuki uses the YouTube API Services to:

  • read channel information and public statistics (subscriber, view and video counts);
  • read and edit the owner's own video titles, descriptions and tags;
  • upload videos prepared by the owner, always as private first, and published only after the owner approves.

Kuki does not access comments, messages, viewer lists or any personal data of other people.

3. How data is stored and shared

  • The access token and any channel data are stored only on the owner's own computer.
  • Data is never sold, rented or shared with third parties, and never used for advertising.
  • Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

4. YouTube and Google

Kuki uses the YouTube API Services. By using Kuki you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

5. Children's privacy

The Zuppi channel is set as "made for kids" on YouTube. We do not collect personal information from children. Comments are turned off by YouTube for this channel.

6. Revoking access and deleting data

Access can be revoked at any time on the Google Account permissions page. Locally stored tokens and data are deleted on request or when access is revoked, within 7 days.

7. Contact

Questions about this policy: zuppi.video@gmail.com
